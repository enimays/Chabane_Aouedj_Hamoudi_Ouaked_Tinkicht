## 📖 Présentation

**CineOra** est une application web permettant la réservation de tickets de cinéma en ligne. Le site offre une expérience simple et intuitive permettant aux utilisateurs de consulter les films disponibles, sélectionner une séance et réserver leurs places en quelques clics.

L'objectif principal du projet est de mettre en pratique les concepts fondamentaux du développement web front-end à travers une application interactive et responsive.

---

## ✨ Fonctionnalités

### 🎥 Gestion des Films

- Affichage dynamique des films à l'affiche.
- Consultation des informations des films.
- Filtrage des films par catégorie.

### 👤 Authentification

- Création de compte utilisateur.
- Connexion sécurisée avec validation des formulaires.
- Gestion de session simulée via `localStorage`.

### 🎫 Réservation

- Sélection de la séance :
  - Date
  - Heure
  - Salle

- Choix du type de ticket :
  - Normal
  - Étudiant
  - Enfant

- Sélection du nombre de tickets.

### 💰 Paiement

- Calcul automatique du montant total en Dinars Algériens (DA).
- Validation de la réservation avant paiement.

### 📱 Responsive Design

- Compatible avec les ordinateurs.
- Adapté aux smartphones et tablettes.

## 🚀 Guide d'Utilisation

### 1. Lancer l'application

Ouvrir le fichier **index.html** dans un navigateur web.

### 2. Accéder à l'accueil

- Une vidéo d'introduction est affichée.
- Une image d'accueil apparaît ensuite.
- Cliquer pour accéder à la plateforme.

### 3. Choisir un film

- Parcourir les films disponibles.
- Utiliser les filtres de catégories si nécessaire.
- Cliquer sur le bouton **"Buy"** du film souhaité.

### 4. Réserver une séance

- Sélectionner :
  - La date
  - L'heure
  - La salle

- Cliquer sur **Continue**.

### 5. Choisir les tickets

- Sélectionner le type de ticket.
- Choisir la quantité désirée.

### 6. Paiement

- Vérifier le montant total.
- Procéder au paiement pour finaliser la réservation.
