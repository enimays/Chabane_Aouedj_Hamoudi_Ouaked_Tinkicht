                                                             cineora site de reservation de tickets de cinéma

1.DESCRIPTION DU SITE:
-CineOra est un mini site web de vente de tickets de cinéma.
 Il permet aux utilisateurs de consulter les films disponibles, de choisir une séance, de sélectionner le type et le nombre de tickets, puis de finaliser leur réservation.
-Le site propose les fonctionnalités suivantes :
 Affichage dynamique des films avec filtrage par catégorie.
 Système d’inscription et de connexion avec validation.
 Sélection de séances (date, heure, salle).
 Choix des tickets (Normal, Étudiant, Enfant).
 Calcul automatique du total en DA.
 Authentification simulée avec localStorage.
 Interface responsive adaptée mobile et desktop.

2.PAGES DU SITE:
- index.html       : Page d'accueil avec les films à l'affiche
- signup.html      : Page d'inscription
- essa.html        : Page de connexion
- reservation.html : Page de réservation de tickets

3.INSTRUCTIONS D'UTILISATION:
1. Ouvrir index.html dans un navigateur.
2. Une vidéo d'introduction se lance, puis une image d'accueil s'affiche.
3. Cliquer pour accéder à la page d'accueil.
4. Parcourir les films disponibles et filtrer par catégorie si besoin.
5. Cliquer sur "Buy" sur le film souhaité.
6. Sur la page de réservation, choisir une séance (date, heure, salle).
7. Cliquer sur "Continue " puis sélectionner le type
   et le nombre de tickets souhaités.
8.Puis effectuer le payment.
